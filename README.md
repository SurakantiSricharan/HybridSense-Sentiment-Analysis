# HybridSense - Sentiment Analysis

## Project Title

HybridSense: A Lightweight Hybrid Deep Learning Framework for Real-Time Neutral and Ambivalent Sentiment Detection in Social Media Streams

## Description

This project develops an AI-based sentiment analysis system that classifies text into four categories:

- Positive
- Negative
- Neutral
- Ambivalent

The system uses Natural Language Processing and Deep Learning techniques including CNN, BiLSTM, Attention mechanisms, and DistilBERT.

A Streamlit web application will be developed to provide real-time sentiment prediction and visualization.
